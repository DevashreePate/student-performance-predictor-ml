# 🎓 Student Performance Predictor

## 📌 Overview
This project predicts students' math scores based on demographic and academic features using Machine Learning.

## 🚀 Features
- Data preprocessing and encoding
- Correlation analysis using heatmap
- Regression model for prediction
- Model evaluation using R² Score and MSE

## 📊 Dataset
- Students Performance Dataset (Kaggle)
- Features: gender, parental education, lunch, test preparation, reading & writing scores

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
